ระบบสั่งอาหาร
กรอก URL ของ Google Apps Script เพื่อเชื่อมข้อมูลกับ Google Sheets
1
สร้าง Google Sheets
สร้างชีทชื่อ เมนู (ชื่อเมนู | ราคา | หมวดหมู่ | หมายเหตุ) และชีท คำสั่งซื้อ (ระบบสร้างให้อัตโนมัติ)
2
ติดตั้ง Apps Script
Extensions → Apps Script → วางโค้ดจากไฟล์ apps-script.js → Deploy → New Deployment → Web App → Anyone
3
ใส่ URL ด้านล่าง
คัดลอก URL ที่ได้จาก Apps Script มาวางแล้วกดเริ่มใช้งาน
กรุณาใส่ URL ที่ถูกต้อง
เปิด Apps Script โดยตรง
